# Fractured-space-cheat-menu
a simple cheat menu for fractured space 
First public release.

Features:
- Allied and enemy ship spawning
- bot difficulty selection
- Allied/enemy God Mode
- Live ship roster
- Ship deletion
- Debug difficulty preset output

For local/offline spserver.exe only.

dl the [cheat.menu.zip]

Windows security software may warn about or block the trainer because it reads/writes memory in spserver.exe
